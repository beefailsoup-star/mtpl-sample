# mtpl-sample — Multilingual Code Sample Collection

多語言程式碼範例 · 300+ samples across 6 languages

---

A curated collection of 300+ sample code files spanning 6 programming languages, designed for learning, reference, and code reuse. Each directory contains 50 meaningful, production-quality sample files covering a wide range of concepts — from basic utilities to design patterns and data structures.

## Language Directories

| Directory | Language | Contents |
|-----------|----------|----------|
| **Vue/** | Vue 3 | 50 SFC components — UI components, charts, forms, media players |
| **JS/** | JavaScript | 50 modules — utilities, algorithms, data structures, async patterns |
| **PY/** | Python | 50 modules — file I/O, networking, design patterns, algorithms |
| **TS/** | TypeScript | 50 modules — type-safe utilities, patterns, data structures |
| **CPP/** | C++ | 50 modules with headers — algorithms, data structures, networking, system |
| **CSHARP/** | C# | 50 classes — design patterns, services, data structures, security |

## Features

- **300+ samples** — broad coverage across 6 major languages
- **Production-quality** — each sample follows idiomatic conventions for its language
- **Ready to run** — minimal dependencies, copy and execute
- **Covers the spectrum** — from basic syntax to advanced patterns (Singleton, Observer, Factory, etc.)
- **Consistent structure** — each directory is self-contained with 50 standalone files

Browse individual files directly — no build tools or extra setup required for most samples.
